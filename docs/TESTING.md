# TESTING

Запуск (только stdlib, без pytest):
```bash
cd KNOWLEDGE_SYSTEM
python3 -m unittest discover -s tests -t .          # все тесты (≈110, ~2 с)
python3 -m unittest tests.test_invariants           # инварианты раздела XL
bin/knowledge demo                                  # 10 детерминированных сценариев
python3 tools/bench.py 20000                        # бенчмарк ядра
```
`z3-solver` необязателен: без него SMT-тест проверяет типизированный ответ `SMT_UNAVAILABLE`.

## Детерминизм
- Golden-демо: два прогона дают байт-идентичный вывод (временные рабочие пространства, фиксированные часы).
- Replay журнала ≡ инкрементальное состояние ≡ состояние из кеша (`test_replay_is_deterministic_and_incremental_equals_full`, `tools/bench.py`).
