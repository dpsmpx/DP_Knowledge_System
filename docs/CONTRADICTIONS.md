# CONTRADICTIONS — паранепротиворечивость и аргументация

Код: `ksys/query/answers.py` (вердикты, противоречия), `ksys/argumentation/grounded.py`, `ksys/query/hypothesis.py`, `ksys/validation/schema.py`, `ksys/query/smt.py`.

## 1. Логика Белнапа (FOUR)
Для литерала `L` поддержка `L` и поддержка `¬L` вычисляются **независимо**:

| поддержка L | поддержка ¬L | вердикт |
|---|---|---|
| да | нет | PROVEN |
| нет | да | DISPROVEN |
| да | да | **BOTH** (CONTESTED) |
| нет | нет | **UNKNOWN** |

Из `A ∧ ¬A` не следует всё: вывод идёт только по правилам, а правила срабатывают по конкретным посылкам. Противоречие про кофе не влияет на ответы про чай (тест `test_contradiction_is_local_not_explosive`). Конъюнкция вопросов вычисляется по решётке FOUR.

Отсутствие знания — UNKNOWN, а не FALSE. DISPROVEN появляется только при явном отрицательном знании.

## 2. Что считается противоречием
1. **Прямое:** `p` и `not p` с совместимыми контекстами и пересекающимися интервалами (в auth- или full-слое).
2. **Схемное:** нарушение функциональности (два значения возраста на пересекающемся интервале), асимметрии, иррефлексивности, диапазона, enum, типов; нарушение пользовательского ограничения-запрета `:- тело`.
3. **Числовое:** невыполнимость системы `value`/`bound`/`attr_cmp` (SMT unsat core).
4. **Непересекающиеся классы:** `Ни один кот не является собакой` + `is_a(x, кот)` + `is_a(x, собака)` → правило выводит `not is_a(x, собак)` → прямое противоречие.

## 3. Что показывается для каждого противоречия
- оба утверждения (ID, KSF, пересказ, ASSERTED/DERIVED);
- пересечение интервалов и общий контекст;
- **базис** каждой стороны: записи, решения человека (J:…, кто, когда), источники и тексты фрагментов;
- зависимые выводы (что изменится, если одну сторону отозвать);
- слой: `auth` (в принятом знании) или `full` (с участием заявлений).

## 4. Аргументация для спорных утверждений
Граф Дунга с grounded-семантикой и предпочтениями:
- **аргументы** — каждая поддержка `L` или `¬L` (вывод с базисом) и явные аргументы человека (`Evidence`: «премиссы поддерживают/атакуют цель»);
- **сила** — `auth` (только авторитетные основания) или `claim`;
- **атаки** — аргументы противоположных сторон опровергают друг друга. Атака успешна (defeat), если сила атакующего не меньше силы цели;
- **разметка** — IN / OUT / UNDEC (наименьшая неподвижная точка).

Следствие: заявление не может победить принятый факт («Шум не вызывает бессонницу» как факт делает заявление «шум вызывает» OUT → REFUTED). Два равносильных заявления друг против друга дают UNDEC → CONTESTED. Это логическая разметка, а не числовой скор.

## 5. Разрешение
Противоречие не исправляется автоматически. Человек решает сам: `retract` одну из сторон, `revise`, сузить интервал или контекст, либо оставить противоречие (оно будет показано как BOTH). Каждое решение попадает в журнал, и TMS пересчитывает только затронутое.
