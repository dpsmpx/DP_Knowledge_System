# MODEL-M2 — локальное сравнение вариантов весов (первый срез)

**Статус:** Android UI и чистый Java-расчёт; требуется Android CI и
физическая проверка интерфейса. Это **не** inference и не бенчмарк.

## Что доступно

- В **Управление локальными моделями → [тип] → Каталог и сравнение** добавлен
  пункт **Сравнить варианты весов на устройстве**. В сводке присутствуют
  все семь проверяемых файлов каталога соответствующих трёх ролей **и**
  импортированные пользователем варианты той же роли, которых нет в каталоге.
  Если для персонализации предложены только алгоритмы без готовых весов,
  сводка появится после импорта своего файла. Все четыре типа остаются
  независимыми и необязательными.
- Каталог выделяет уже установленный файл; его карточка открывает действия
  над установленной моделью вместо повторной загрузки. Ничего не скачивается
  при открытии списка или сравнении.
- Установленный файл определяется по **роли и SHA-256**, а не по похожему
  имени; его размер берётся из локальной регистрации. Размер ещё не
  установленного файла — **приблизительные MB каталога**, а не запрос к
  серверу. Разные пользовательские варианты отображаются отдельно.
- Для неустановленного веса сравниваются приблизительный размер файла и
  доступное место в разделе приложения с дополнительным запасом **16 МиБ**,
  как при записи файлов модели. Итог — только «возможно поместится / может
  не хватить / место неизвестно»; это **не** запрет скачивать большие модели.
- RAM — текущий `ActivityManager.MemoryInfo.availMem` от ОС. Показывается
  процент **размера файла весов относительно этого снимка**, а не оценка
  пикового RAM процесса. Модель может использовать mmap, больше RAM на
  активации и KV-кэш или вообще не иметь совместимого runtime. Даже
  «вес меньше доступной RAM» **не** означает возможность запуска.

## Инварианты и ограничения

- Ни модель, ни tokenizer, ни заметки/журнал не открываются для сравнения:
  используется только приватная регистрация моделей и публичный встроенный
  каталог. Нет inference, вызовов API, разрешений на сеть или фоновых задач.
- Компаньоны в расчёт размера веса **не включены**. Свободное место и
  доступная RAM могут измениться сразу после открытия экрана; реальная
  загрузка продолжает выполнять собственную проверку места, размера,
  заголовка и (при наличии) ожидаемого SHA-256.
- Пока нет измеренных по каждому варианту времени токенизации, времени
  ответа, RAM high-water, GPU/NPU/CPU, нагрева, батареи, скорости/качества.
  Эти метрики допустимо добавлять только после отдельного запуска
  пользователем на синтетических тестах по четырём ролям и после появления
  валидированных Android backend/tokenizer. Совместимость не утверждается.

## Тестовая матрица

- JVM: два и три варианта каталога, персональный импорт вне каталога,
  выделение роли+SHA, локальный выбранный файл, неверное/осиротевшее
  предпочтение, точные граничные значения свободного места с запасом,
  неизвестная RAM/диск, сравнение веса с RAM, неизменяемость результата.
- Android CI: сборка RU/EN ресурсов, JVM-тесты, unsigned debug APK.
- На реальном устройстве позже проверить TalkBack, шрифт 200%, длинные
  имена моделей, прокрутку при множестве импортированных вариантов, смену
  объёма свободной RAM и отсутствие незапрошенной сети.
