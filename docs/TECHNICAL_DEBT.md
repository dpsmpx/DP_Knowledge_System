# DP Knowledge System — реестр технических долгов

**Проверено по состоянию на 2026-11-19.** Это перечень **известных**, а не
гарантированно всех возможных дефектов. **Продуктовые решения владельца
утверждены 2026-11-18** в [OWNER_DECISIONS.md](OWNER_DECISIONS.md).
Статусы: **открыт** — не внедрено/не проверено; **частично** — есть прототип,
ручная проверка или ограничения; **решение** — конкретная инженерная
деталь ещё проектируется; **отложен** — не в ближайшем v1.

Источники: исходники и документация `main`,
[интеграционный roadmap](https://github.com/dpsmpx/DP_Knowledge_System/blob/feature/knowledge-android/docs/ANDROID_ROADMAP.md),
[PR #7](https://github.com/dpsmpx/DP_Knowledge_System/pull/7),
[PR #16](https://github.com/dpsmpx/DP_Knowledge_System/pull/16).
Если запись противоречит фактическому тесту, обновить её с доказательством.
