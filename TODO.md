# DP Knowledge System — вопросы и внешняя приёмка Stage 21

Состояние: 20.11.2026. Это перечень вопросов, требующих решения владельца,
и проверок, которые нельзя честно выполнить без его Android-устройства.
Не содержит личных заметок, имён устройств, паролей и учётных данных.

## Решения, уже принятые (не переспрашивать)

- Сначала SAF/Syncthing/Google Drive через стандартную папку Android;
  собственная автоматическая передача — после безопасного протокола.
- Для сопряжения — QR либо одноразовый проверочный код, доверие отзывается.
- Конфликты остаются отдельными ветвями до ручного подтверждения; ничего
  не объединяется по дате, источники Markdown никогда не перезаписываются.
- Локальный ежедневный зашифрованный backup — только после явного включения;
  никаких автоматических скачиваний моделей эмбеддингов.
- До 20.11.2026 действовал запрет на APK. Владелец отдельно разрешил
  подписанную **тестовую Stage 21 APK через GitHub Actions → Releases**;
  это не разрешение объявить аппаратную приёмку пройденной.
- Все ответы на открытые вопросы Stage 21 получены через опрос 20.11.2026;
  дальнейшие работы ведутся по зафиксированным решениям ниже.

- [x] **DEV-21-29 — ручные `bind` и `resolve`.** По точному `origin` ищется

  прочтение/нерешённый слот проверяются по локальной грамматике. Две явные
  операции UI, повторная проверка подписанного inbox, SHA исходного текста,
  локальной/удалённой вершины; только новое причинное локальное событие.
  Изменённая заметка, неизвестное прочтение, локальный выбор или занятая
  привязка отклоняются. Если локальная библиотека ещё не индексирована,
  пользователь должен запустить существующую индексацию вручную. Аппаратная
  QA не выполнена.
- [x] **DEV-21-30 — ручные `revise`, `split`, `merge`.** Каждое подписанное
  предложение отдельно сверяет все затронутые *активные локальные* записи,
  роли, уникальность и каноничность новых узлов, типы и структурные ошибки.
  UI показывает прежние записи и полное предлагаемое содержание, затем
  просит отдельное повторное согласие. Запись — новое локальное событие с
  causal-ссылками; чужое утверждение о provenance **не** принимается за
  локальное доказательство. Непроверенные / конфликтующие / слишком большие
  изменения блокируются. Аппаратная QA не выполнена.

  или открытия реального индекса read/write. Android unit CI обеих flavor
  [#44737077549](https://github.com/dpsmpx/DP_Knowledge_System/actions/runs/44737077549)
  и Python CI [#44737077585](https://github.com/dpsmpx/DP_Knowledge_System/actions/runs/44737077585)
  прошли. Подписанный [Stage21 QA prerelease #22](https://github.com/dpsmpx/DP_Knowledge_System/releases/tag/knowledge-stage21-qa-22-63ca61e4a7)
  с этой диагностикой опубликован после успешного
  [Actions #44737491286](https://github.com/dpsmpx/DP_Knowledge_System/actions/runs/44737491286);
  APK и `.sha256` проверены в GitHub Releases. В отчёте владельца #22

  задача выполнена, но **SQLITE-46 и оба WARN остаются открытыми**:
