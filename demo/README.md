# Демо-набор

`vault/` — мини-хранилище для сценариев (сценарий 10 трассирует ответ до фрагмента `people/alex.md`).
Запуск: `bin/knowledge demo` (работает во временном рабочем пространстве, реальный журнал не трогает).
Ожидаемый вывод — `DEMO_OUTPUT.md`; golden-тест `tests/test_demo.py` сверяет его байт-в-байт.
